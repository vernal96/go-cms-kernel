# Документация GO CMS

Руководства по запуску, профилям и удалению пресетов описывают приложение
[go-cms starter](https://github.com/vernal96/go-cms). Контракты модулей и
шаблонов принадлежат этому репозиторию.

1. [Развертывание проекта с нуля](deployment.md) — подготовка окружения, запуск backend и админки, первичная настройка.
2. [Какие пресетные элементы можно удалить из кода](removing-presets.md) — состав starter и безопасный порядок удаления.
3. [Работа с профилями](profiles.md) — создание, изменение и удаление профиля, примеры полей настроек сайта и их группировки по табам.
4. [Проверки полей](modules/core/fields.md) — типизированные валидаторы и примеры объявлений.
5. [Архитектура запуска и конфигурация](startup.md) — bootstrap, HTTP и консоль, defaults ENV и ручной запуск seeds.
6. [Справочник модулей](modules/README.md) — обзор всех модулей kernel и переходы к сущностям, API, виджетам, полям, командам и фоновой работе.
7. [Подключение модулей](modules/adding-modules.md) — примеры конфигурации каждого модуля и обязательные зависимости.
8. [Разработка шаблонов страниц](templates.md) — определения, поля, зоны, статические и ресурсные виджеты.
9. [Контекст Core-виджетов](modules/core/widgets.md#контекст-пользовательских-виджетов) — снимки ресурса, запросы сайта и проекция публичных настроек.

[Единый префикс HTTP API](http-api.md) — внешние адреса, регистрация маршрутов модулей и исключения.
