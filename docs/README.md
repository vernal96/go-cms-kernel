# Документация GO CMS

Руководства по запуску, профилям и удалению пресетов описывают приложение
[go-cms starter](https://github.com/vernal96/go-cms). Контракты модулей и
шаблонов принадлежат этому репозиторию.

1. [Развертывание проекта с нуля](deployment.md) — подготовка окружения, запуск backend и админки, первичная настройка.
2. [Какие пресетные элементы можно удалить из кода](removing-presets.md) — состав starter и безопасный порядок удаления.
3. [Работа с профилями](profiles.md) — создание, изменение и удаление профиля, примеры полей настроек сайта и их группировки по табам.
4. [Поля Core](modules/core/fields.md) — типы и типизированные Go-конструкторы, проверка значений и настройка файлового поля с плитками; [контракт проверок полей](field-validation.md) — каталог валидаторов, ошибки и расширение модулем; [окончательное удаление файла](modules/core/file-field-deletion.md) — проверки ссылок, жизненный цикл владельца и polling статуса.
5. [Архитектура запуска и конфигурация](startup.md) — bootstrap, HTTP и консоль, defaults ENV и ручной запуск seeds.
6. [Справочник модулей](modules/README.md) — обзор всех модулей kernel и переходы к сущностям, API, виджетам, полям, командам и фоновой работе; [Core API](modules/core/api.md) — в том числе публичность сайта, доступ гостей и публикация ресурсов; [консольные команды Core](modules/core/commands.md) — параметры и примеры команд пользователей, групп и разрешений; [счётчик просмотров Core](modules/core/resource-views.md) — контракт накопителя, фильтрация запросов и запись статистики.
7. [Подключение модулей](modules/adding-modules.md) — примеры конфигурации каждого модуля и обязательные зависимости.
8. [Contributions модулей](contributions.md) — декларативные и runtime-расширения, их типизированные контракты, зависимости и изоляция.
9. [Разработка шаблонов страниц](templates.md) — определения, поля и статические/ресурсные виджеты; [зоны виджетов](widget-areas.md) — порядок элементов, метаданные редактора и восстановление удалённых зон.
10. [Core-виджет полей ресурса](modules/core/widgets.md#поля-текущего-ресурса) — выбор полей шаблона и формат `data.fields`; [контекст Core-виджетов](modules/core/widgets.md#контекст-пользовательских-виджетов) — снимки ресурса, запросы сайта и проекция публичных настроек.

[Единый префикс HTTP API](http-api.md) — внешние адреса, регистрация маршрутов модулей, хлебные крошки публичного ресурса и исключения.
