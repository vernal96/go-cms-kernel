# Admin: сущности

`admin` использует сущности `core`, но не вводит собственные хранимые доменные сущности.

- **Пользователь (`User`)**: учётная запись с login, email, именем, состоянием блокировки, настройками отображения и членством в группах. Создайте группы и назначьте права, затем добавьте пользователя в подходящие группы.
- **Группа (`Group`)**: именованный набор разрешений и правил site access. Учитывайте, что встроенная защищённая группа администратора имеет специальные ограничения.
- **Профиль текущего пользователя**: представление пользовательских данных, настроек и аватара для редактирования самим вошедшим пользователем.
- **Сессия и навигация**: вычисляемые ответы из текущей аутентификации, разрешений и зарегистрированных пунктов меню модулей.
- **Dashboard**: сводка доступных сайтов и CMS-данных, не отдельная таблица, редактируемая как контент.

Типичный сценарий — проверить каталог разрешений, создать или обновить группу, затем назначить группу пользователю. Проверки доступа остаются на сервере и не заменяются сокрытием пунктов UI.
