# Admin

`admin` добавляет административную сессию, профиль пользователя, панель, навигацию и HTTP-управление идентификацией. В Starter модуль уже подключён.

См. [сущности](entities.md), [API](api.md) и [виджеты](widgets.md). Модуль зависит от обязательного `core` и использует его пользователей и авторизацию. Собственные content widgets, field types, консольные команды и фоновые jobs модуль не добавляет.

Подключение: `admin.New()`. Модуль не принимает конфигурацию, кэш или файловые привязки.

Пошаговое подключение и зависимости: [руководство по модулям](../adding-modules.md).
