# Search: данные поиска

Search не создаёт отдельные редактируемые сущности и не требует отдельного reindex job. Он читает ресурсы `core` напрямую.

В выборку входят публичные, доступные для маршрутизации ресурсы с `is_searchable` и активным периодом публикации. Для LibraryItem также требуется доступная публичная библиотека с активным периодом публикации. Настройка `is_searchable` библиотеки отдельно управляет поиском самой библиотеки.

Индексируются сохранённые title, annotation и content. Произвольные template fields и отрендеренный виджетами текст не участвуют. Изменения ресурса становятся видны при следующем поисковом запросе.
