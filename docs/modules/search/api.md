# Search: API

Модуль регистрирует публичный маршрут `GET /api/search`:

```http
GET /api/search?q=electricity&page=1&per_page=20
Host: example.test
```

Ответ содержит `items` и `pagination`; элементы включают `id`, `storage_kind` (`tree` или `library_item`), `title`, `url`, `annotation` и `score`.

## Query-параметры

| Параметр | Описание |
| --- | --- |
| `q` | Строка поиска после trim: обязательна, 3–200 символов. |
| `page` | Номер страницы, целое число от 1; по умолчанию `1`. |
| `per_page` | Размер страницы от 1 до 50; по умолчанию `20`. |

Например, запрос `GET /api/search?q=electricity&page=2&per_page=10` вернёт вторую страницу выдачи по 10 элементов. Тело запроса не используется. Некорректные параметры возвращают `400`; пустая выдача — `200` с пустым `items`.

Site выбирается стандартной обработкой Host/runtime; параметр клиента `site_id` не переключает сайт. Применяются правила видимости и чтения core.
