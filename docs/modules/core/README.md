# Core

`core` — обязательный базовый модуль и первый в профиле. В Starter он уже подключён.

Здесь собраны сведения о [сущностях](entities.md), [API](api.md), [виджетах](widgets.md), [типах полей](fields.md) и [консольных командах](commands.md).

**Зависимости:** нет. `core` предоставляет сайты, ресурсы, библиотечные элементы, типы ресурсов, шаблоны, файлы, медиа, пользователей, группы и доступ. Site settings профиля описаны отдельно в [работе с профилями](../../profiles.md).

Подключение: `core.New(core.Config{...})`. Кэш задаётся в `core.Config.Caches`; поддерживаются aliases `durable`, `hot`, `thumbnails`. Каждый alias ссылается на объявленное приложением хранилище.

Пошаговое подключение и зависимости: [руководство по модулям](../adding-modules.md).
