# Forms: сущности

Все сущности привязаны к сайту, в runtime которого подключён модуль.

| Сущность | Назначение и порядок работы |
| --- | --- |
| **Form** | Уникальная в пределах сайта форма с кодом, именем и флагом `enabled`. Создайте форму, соберите её схему и включите после проверки. |
| **FormField** | Поле с кодом, типом, валидацией и флагами показа на сайте/в результатах. Код становится ключом отправляемого значения. |
| **Element** | Статический текст, заголовок, изображение или submit button; не сохраняет значение пользователя. |
| **LayoutNode** | Размещение поля, элемента или контейнера (`group`, `slide`) с порядком и вложенностью. |
| **Status** | Статус результата; форма задаёт начальный статус и доступные переходы. |
| **Action** | Включаемое действие на событие `submitted` или `status_changed`; action type валидирует собственную конфигурацию. Встроена отправка письма через `mail`. |
| **Result / ResultValue / ResultUpload** | Отправка и снимок значений полей. Upload хранится отдельно от обычных значений. Результату присваивается статус и время. |
| **ActionExecution** | Состояние фонового запуска действия: pending, running, retryable, succeeded или failed. Используется для диагностики/повторов. |

Сценарий: создать форму `feedback`, добавить поля `name` и `message`, настроить элементы и layout, задать статус по умолчанию, затем добавить действие и включить форму. Для показа разместите виджет `form` на ресурсе.
