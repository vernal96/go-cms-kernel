# Forms: виджеты

Forms регистрирует два виджета `core.widget`:

| Код | Параметры | Результат |
| --- | --- | --- |
| `form` | `{"form_id":17}` | Схема формы и `submit_url` для публичного клиента |
| `results` | `{"form_id":17,"per_page":20}` | Колонки, публичные значения, pagination и `results_url` |

`per_page` для `results` — от 1 до 100, по умолчанию 20. Виджет относится к сайту своей формы; выключенная или чужая site-scoped форма не отображается.
