# Mail: фоновые задачи

- Job `mail.send` вызывает настроенный transport, фиксирует DeliveryAttempt и применяет настроенное число повторов.
- Task `mail.history_retention` запускается при положительном сроке хранения и очищает старую историю.
- Task `mail.spool_cleanup` удаляет временные вложения при включённом spool.

Все задачи относятся к site runtime и запускаются механизмом jobs/background kernel. Отдельной команды shell модуль не добавляет. Транспорт доставки — подключаемая приложением зависимость; конфигурация SMTP задаётся на стороне приложения.
