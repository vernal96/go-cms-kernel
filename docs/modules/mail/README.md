# Mail

`mail` предоставляет шаблоны, постановку писем в очередь и историю попыток доставки. Зависит от `core`; в Starter не включён.

См. [сущности](entities.md), [API](api.md), [виджеты](widgets.md) и [фоновые задачи](background.md). Для доставки приложение подключает transport; для SMTP доступны настройки соответствующего транспорта. Параметры `mail.Config` управляют лимитами, повторами, retention и attachment storage.

Подключение: `mail.New(mail.Config{...})`. Собственные настройки включают `Filesystems []filesystem.Binding` с alias `mail.SpoolFilesystemAlias`. При `SpoolEnabled` привязка обязательна; диск должен быть приватным и поддерживать ограниченное сканирование для очистки. Лимиты, транспорт и `UploadStorage` проверяются перед запуском, даже если сайтов с этим модулем ещё нет.

Пошаговое подключение и зависимости: [руководство по модулям](../adding-modules.md).
