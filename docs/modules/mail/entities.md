# Mail: сущности

| Сущность | Назначение и порядок работы |
| --- | --- |
| **Template** | Site-scoped схема письма: код, адреса, subject, text/HTML body, attachments и типизированные variables. Создайте шаблон, проверьте его через preview и затем включите. |
| **Message** | Зафиксированный запрос доставки со снимком шаблона/значений, адресатами, origin и состоянием. Постановка сообщения в очередь не означает, что получательское mail server его принял. |
| **DeliveryAttempt** | История одного вызова transport с driver, кодом ответа и безопасным описанием ошибки. Используйте для диагностики повторных/неудачных отправок. |
| **Variable** | Типизированное значение шаблона, проверяемое по field definition и передаваемое при preview/send. |

Пример переменных шаблона — обязательные `name` типа `string` и `recipient_email` типа `email`. Значения передаются с ключами этих переменных.
