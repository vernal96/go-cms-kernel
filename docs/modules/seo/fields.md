# SEO: поля редактора

SEO расширение редактора показывает следующие значения:

| Ключ | Назначение |
| --- | --- |
| `title_template` | Шаблон заголовка |
| `description_template` | Шаблон описания |
| `keywords_template` | Шаблон списка ключевых слов |
| `canonical_template` | Шаблон canonical URL |
| `robots_index`, `robots_follow` | Разрешить индексацию и переходы |
| `og_title_template`, `og_description_template` | Open Graph заголовок и описание |

Это поля `resourceextension` metadata, а не новые типы `core.field`. Поддерживаемые переменные перечисляет metadata модуля в редакторе; примеры и список переменных см. в [сущностях SEO](entities.md).
