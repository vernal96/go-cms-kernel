# Зоны виджетов

Шаблон объявляет упорядоченный `template.Layout` из зон `template.Area`:

```go
Layout: template.Layout{
    {Code: "main", Label: "Основная область", AdminSpan: 16},
    {Code: "aside", Label: "Боковая область", AdminSpan: 8},
    {Code: "footer", Label: "Подвал"},
},
```

Коды должны соответствовать `[a-z][a-z0-9_-]*` и быть уникальными в шаблоне;
`default` зарезервирован. Название обязательно. `AdminSpan` задаёт ширину зоны
в административной сетке от 1 до 24; ноль означает 24. Редактор сохраняет порядок
объявления, переносит зоны на следующую строку при заполнении 24 колонок и
показывает их на всю ширину экрана ниже точки `md` (992 px). Ширина зоны не
меняет `columns` отдельного виджета (от 1 до 12).

`Items == nil` добавляет слот `template.ResourceWidgets{}`. Явный список `Items`
задаёт точный порядок статических виджетов и не более одного слота:

```go
{Code: "main", Label: "Страница", Items: []template.Item{
    template.Widget{Widget: corewidgets.Content},
    template.ResourceWidgets{},
}},
```

Статические виджеты шаблона отображаются в редакторе ресурса перед или после
слота в объявленном порядке. Для каждого показываются название и описание из
определения виджета; у такого блока нет действий редактирования. Редактор
размещает ресурсные виджеты только в позиции `ResourceWidgets{}`. Пустой список
или список только со статическими виджетами оставляет контейнер видимым, но
не позволяет добавлять в него ресурсные виджеты.

## Зона `default` и удалённые зоны

Если шаблон не объявляет зоны, редактор получает одну системную зону `default`
с названием «Страница сайта», шириной 24 и неявным слотом ресурсных виджетов.
Если зоны объявлены, `default` появляется последней только пока в ней есть
привязки, в том числе выключенные. Существующие привязки для удалённых зон или
зон без слота отображаются и выводятся в `default`. Их сохранённый `area` не
меняется до явного переноса. Если исходная зона появляется снова и поддерживает
слот, привязки возвращаются в неё.

Явные привязки `default` идут первыми; восстановленные привязки следуют за ними
в порядке исходного кода зоны, позиции и ID. Компоновка не записывает изменения
в базу данных. Кэшированные привязки сохраняют исходный код зоны, а разрешение
зависит от текущего шаблона. Сохранение ресурса/шаблона, восстановление истории
и перенос сайта сохраняют эти коды.

## Контракт метаданных редактора

В metadata управления `widget_areas` — упорядоченный массив объявленных зон.
Если шаблон не объявляет зоны, массив содержит системный `default`. Каждый
элемент содержит `code`, `label`, `admin_span`, `supports_resource_widgets` и
`items`. `items` — скомпилированный порядок элементов зоны:

```json
{
  "code": "main",
  "label": "Основная область",
  "admin_span": 16,
  "supports_resource_widgets": true,
  "items": [
    {"kind": "widget", "code": "core_content"},
    {"kind": "resource_widgets"}
  ]
}
```

Для статического виджета `code` — код виджета, разрешённый при сборке runtime
сайта. Конфигурация (`view`, параметры и отступы) в этих метаданных не
передаётся: админка берёт название и описание из общего списка определений
виджетов. Элемент слота содержит только `kind`. Для зоны без элементов `items`
является пустым массивом. В неявной `default` метаданные содержат один элемент
`{"kind":"resource_widgets"}`.

Management binding `area` — сохранённый код зоны. Клиенты помещают привязки,
код которых отсутствует среди редактируемых зон, в `default` и добавляют этот
контейнер при необходимости. CRUD URL и проверки optimistic version не
меняются. Создание требует редактируемую объявленную зону или `default`. Полный
запрос перестановки сохраняет исходные коды зон у неизменённых привязок; для
изменённого кода требуется допустимая целевая зона. Явный перенос восстановленной
привязки в `default` сохраняет `area: "default"`. Восстановленные привязки идут
после явных привязок `default` до переноса.

Публичный `widgets` — объект с кодом зоны в качестве ключа и массивом уже
скомпонованных виджетов. Объявленные пустые контейнеры остаются `[]`; `default`
подчиняется правилам выше. Выключенная привязка делает `default` видимой, но
сама не выводится. Ресурс без шаблона возвращает пустой объект. Названия зон и
их ширина не входят в публичный ответ. Порядок ключей JSON не задаёт порядок
разметки. Подробнее о полях ответа и путях API — в [описании HTTP API](http-api.md#динамические-зоны-виджетов),
а определения шаблонов — в [разработке шаблонов страниц](templates.md).
